# Security Policy

## Reporting Vulnerabilities

Please report security issues privately by opening a GitHub security advisory when available, or by contacting the repository maintainer through the public GitHub profile.

Do not disclose exploitable details publicly until there is a fix or mitigation.

## Data Safety

This project is designed for public-safe workflows. Please do not submit:

- API keys, tokens, passwords, private keys, or `.env` files;
- private local paths or user profile folders;
- browser profiles, logs, caches, or generated private outputs;
- model weight files or large binary artifacts;
- copyrighted or non-public sample media.

Use synthetic fixtures for examples and tests.
