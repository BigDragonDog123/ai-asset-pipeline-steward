# Code of Conduct

## Our Standard

This project aims to be practical, respectful, and welcoming to contributors with different levels of experience.

Expected behavior:

- communicate with patience and clarity;
- focus criticism on work, evidence, and maintainability;
- respect privacy and safety boundaries;
- help keep examples public-safe and legally clean.

Unacceptable behavior:

- harassment, threats, or personal attacks;
- publishing private information without consent;
- submitting secrets, private media, or restricted content;
- repeated bad-faith disruption of project work.

## Enforcement

Maintainers may edit, remove, or reject contributions that violate this code of conduct.
