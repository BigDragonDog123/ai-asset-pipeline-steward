# Roadmap

This roadmap is organized around public maintainer evidence. Each milestone should produce visible commits, tests, issues, releases, or usage examples.

## Milestone 1: Public Scaffold

Status: complete locally.

- README, license, contributing guide, security policy, code of conduct.
- Repo-scoped Codex skill.
- Manifest validator.
- Synthetic fixture manifest.
- Unit tests and CI.
- Codex for OSS readiness document.

## Milestone 2: First Public Release

Status: next.

- Push the repository to GitHub.
- Open 3 to 5 roadmap issues.
- Add a `v0.1.0` release with a short changelog.
- Add a terminal example showing manifest validation.
- Confirm GitHub community profile checklist is green.

## Milestone 3: Useful Maintainer Workflows

Status: planned.

- Add manifest examples for model inventory, smoke gates, review queues, and handoffs.
- Add a public-safe tutorial for extracting local workflows into synthetic fixtures.
- Add validation rules for review signal separation and decision gates.
- Add a small report command for maintainer handoffs.

## Milestone 4: Adoption Evidence

Status: planned.

- Ask for feedback from AI workflow builders and open-source maintainers.
- Track real feature requests and bug reports.
- Add integrations or examples from public-safe projects.
- Collect stars, forks, external links, and usage notes.

## Milestone 5: Codex For OSS Application

Status: wait for public evidence.

- Apply only after the repo is public, active, and has credible usage or ecosystem-value evidence.
- Keep the application under the official 500-character fields where required.
